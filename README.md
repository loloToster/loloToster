# 👋 Hi, I'm loloToster

[![Typing SVG](https://readme-typing-svg.herokuapp.com?font=Fira+Code&weight=500&size=20&pause=1000&color=0EA5E9&vCenter=true&random=false&width=435&lines=Fullstack+Developer;Custom+IoT+Engineer;Open-Source+Enthusiast;Hardware+Tinkerer)](https://git.io/typing-svg)

I am a young fellow who builds versatile software and custom automated systems. From developing robust web platforms and open-source tools to tinkering with electronics, robotics, and custom IoT, I love exploring all sorts of IT and engineering stuff.

## 😃 What I do:

- 🚀 **Software Engineering:** Architecting backends, APIs, and scalable web apps.
- 🤖 **Custom IoT:** Bridging the gap between web interfaces and custom microcontrollers.
- ⚙️ **Mechatronics:** Designing 3D-printed parts, programming PLCs, and building hardware.
- 💡 **Open-Source:** Creating tools and wrappers to make developer lives easier.
